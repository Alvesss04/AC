## 📌 About the Course and Assignments

The Computer Architecture course explores the hardware/software interface, covering instruction set architectures (ISA), assembly language programming, processor design, arithmetic for computers, and memory hierarchy.

The repository includes specific practical assignments implemented in **Assembly**:

## 🧠 Concepts and Acquired Skills
* **Low-Level Programming:** Writing, debugging, and optimizing code in Assembly language.
* **Instruction Set Architecture (ISA):** Understanding register conventions, instruction formats, and addressing modes.
* **Memory and Stack Management:** Managing stack frames, local variables, and subroutine linkages.
* **Hardware-Software Interface:** Bridging high-level logical constructs with machine execution.
